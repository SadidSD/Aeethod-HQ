# 🏭 AEETHOD HQ — Agency & Factory Tycoon RPG

> **Build systems, not just websites.** An immersive 2D isometric agency simulation and factory builder built with **React**, **Vite**, **TypeScript**, **Tailwind CSS**, and **Supabase Realtime**.

---

## 🎮 Features

- **🏢 Interactive Factory & Office Floor**: Explore the Management Boardroom, Frontend Battlestation (Hello Kitty), Backend Systems Workstation (Spider-Man), Lead Designer Creative Studio, and Client Relations Suite.
- **🏗️ Grid & Conveyor Automation Engine**: Place conveyor belts, factory machines, desks, and automated workstations.
- **👑 Executive Management Command Center**: Complete project pipelines, bottleneck radars, 10-section AEETHOD Financial OS (60/20/20 equity split, fixed founder salaries, growth funds, and 6-month profit pools).
- **⚔️ 8-Section Gamified Workstations**:
  - **Frontend Dev Screen**: Project-connected mission board, interactive subtasks with instant XP dopamine loops, skill trees, and boss battles.
  - **Backend Dev Screen**: High-throughput database query optimizations, Redis workers, API schemas, and architecture portfolio.
  - **Lead Designer Screen**: Creative studio dashboard, Figma token exports, micro-interaction transitions, and UI systems.
  - **Client Management Screen**: Full internal CRM control panel, client health overview, live deadline calendar, invoice dispatching, and secure Client Portal management.
- **⚡ Supabase Backend**: Integrated PostgreSQL database, live realtime broadcasts, and client cloud sync.

## 🚀 Quickstart

### 1. Clone the repository
```bash
git clone https://github.com/SadidSD/Aeethod-HQ.git
cd Aeethod-HQ
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure environment variables
Create a `.env` file in the root directory:
```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here
```

### 4. Run database setup (Optional)
Run the SQL schema in `supabase-schema.sql` inside your Supabase project's **SQL Editor**.

### 5. Launch Development Server
```bash
npm run dev
```
Open `http://localhost:5174` in your browser.
